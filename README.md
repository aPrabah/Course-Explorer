# Course Explorer

Course Explorer is a small JavaScript web app that lets users load course data from a JSON file and browse it using filters and sorting options.

## Features

- Upload course data from a JSON file
- Filter courses by different attributes
- Apply multiple filters at once
- Sort courses by title, ID, and semester
- View detailed information for each course
- Handles invalid or incomplete data without crashing

## Technologies

- HTML
- CSS
- JavaScript
- JSON

This project gave me more experience with:

- Working with JSON data
- Classes and object-oriented JavaScript
